# static/landing — the landing page's console screenshot

One screenshot of the Sajag console, shown in the hero window of `/welcome` (the landing page) and captioned there
"Console screenshot · exercise data":

| File | Screen |
|---|---|
| `console-decide-{800,1600}.webp` | Decide — an ambulance (108) corridor request on the Kolkata map, waiting for a named officer |

How it was made (29 Oct 2026): a development deck of this tree, read-only against the Sajag stack on the Kolkata
road network, whose decisions are **exercise data**: the 108 corridor requests, the stolen-vehicle case and the
e-challans are emulated and labelled so on screen ("Emulated", "requested by 108 control (emulated)").
No duty officer was named, so every registration mark stays **masked** (`WB06EM•••1`) and "Plates hidden" shows in
the top bar. Nothing was approved, dispatched or changed to take it. The image was resized and encoded to WebP only;
nothing else was edited.

Third-party content visible inside it keeps its own terms and is credited on screen: satellite imagery
(© Microsoft Corporation, © Maxar, via Cesium ion), map data © OpenStreetMap contributors (ODbL 1.0). The vehicle
pictures inside it are Sajag's own illustrations.
